# Projeto: ONG Exemplo

Conteúdo:
- index.html (página inicial)
- projetos.html (projetos sociais e doações)
- cadastro.html (formulário com validação e máscaras)
- css/style.css
- js/form.js
- images/*

## Instruções
1. Abra `index.html` localmente para testar.
2. Valide cada arquivo HTML no W3C Validator.
3. Faça um repositório público no GitHub e suba o projeto.

## Observações
- Imagens na pasta `images/` em formatos otimizados (webp + png/jpg).
- Formulário usa validação HTML5 + validação CPF via JS (módulo 11).
